# Assignment 4.1 — Student Registration Form

## 1\. Aim

To create a student registration form using HTML that collects the student's personal information, including full name, email, password, phone number, and age.

## 2\. Introduction

An HTML form is used to collect information from users. A student registration form allows students to enter their personal details through input fields and submit the information. HTML provides different form elements and input types to make data entry simple and organized.

## 3\. Objectives

- To understand the use of the HTML `<form>` element.
- To create input fields for student details.
- To use labels for each input field.
- To understand different HTML input types.
- To apply form validation using the `required` attribute.
- To create a submit button for submitting the form.

## 4\. Theory

### A. HTML Form

The `<form>` tag is used to create a form in HTML. It groups input fields and allows users to enter and submit information.

### B. Label Element

The `<label>` tag provides a descriptive name for an input field. It helps users understand what information they need to enter and improves accessibility.

### C. Input Fields

Different input types are used to collect different kinds of information:

- **Full Name:** The text input type is used to enter the student's full name.
- **Email:** The email input type is used to enter an email address and provides basic email-format validation.
- **Password:** The password input type hides the characters entered by the user.
- **Phone Number:** The tel input type is suitable for entering a phone number.
- **Age:** The number input type is used to enter a numerical age.

### D. ID and Name Attributes

The `id` attribute uniquely identifies an HTML element and connects it with its label. The `name` attribute identifies the field when form data is submitted. Each input should have a unique ID and a meaningful name.

### E. Required Attribute

The `required` attribute makes a field mandatory. The browser prevents form submission if a required field is left empty.

### F. Submit Button

The submit button allows users to submit the form. When clicked, the browser performs the applicable form validation and submits the form according to its configuration.

## 5\. Procedure

1. Create an HTML file named `registration.html`.
2. Add the basic HTML document structure.
3. Create a form using the `<form>` tag.
4. Add fields for full name, email, password, phone number, and age.
5. Add a proper label for each input field.
6. Assign a unique `id` and a meaningful `name` to every input.
7. Use appropriate input types and add the `required` attribute to mandatory fields.
8. Add a submit button to complete the form.
9. Save the file and open it in Google Chrome.
10. Test the form by entering details and checking the required-field validation.
11. Take a screenshot of the working form for submission.
